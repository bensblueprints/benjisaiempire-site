Will this really get me to a launched brand in 3 hours?

The 3 hours is the build sprint — positioning, domain, four videos (one 90-min shoot), three landing pages (with Claude Code), and the funnel wiring. Setting up payment processors, recording the videos, and waiting for DNS to propagate will eat your other ~2-3 hours of calendar time. Realistic expectation: one focused day — idea Monday morning, brand live Monday night. If you've never registered a domain or used Canva, plan for two days.

I'm not a designer. Can I really build this myself?

The whole course is built around "you don't need a designer." The Claude Code Design Prompts Pack means you describe what you want and AI writes the HTML. Canva does your wordmark logo. Module 2 picks the fonts and palette for you so you don't get stuck on color theory. If you can copy, paste, and follow instructions for 3 hours, you can ship a brand by the end. If you're a perfectionist, you'll iterate for a week — that's normal. The audience corrects you faster than you can.

Do I need Claude Code or any paid tools?

You'll need Claude or ChatGPT ($20/mo plan covers it), a Namecheap domain (~$12/yr), Canva (free tier works), and a hosting provider — Netlify Drop is free forever for static sites, or you can use GHL custom HTML if you already have a sub-account. Total tooling cost to launch: roughly $32 first month, $12/yr after that. No designer fees, no developer fees, no agency markup.

Both, on purpose. New operators use the full sprint to launch a brand from zero. Existing operators usually skip Module 2 (you already have a name and domain) and run Modules 1, 3, 4, 5, 6 to refresh and re-launch — new positioning, new videos, new landing pages, new lead magnet stack, new content cascade.
